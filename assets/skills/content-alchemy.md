# 内容炼金术 · 口播生成（公开版）

> **怎么用**：把这一整份复制，贴进你常用的 AI 工具，让它把这套规则记成永久技能；以后说一句「创建口播文案」或「生成口播」就触发。
> **它是什么**：把手上的一件真事、一个观点，变成能直接对着镜头念出来的逐字稿。
> **什么时候用**：有素材要出稿、有观点要拍成视频、写出来的东西一股 AI 味要改。
> **不适用**：编故事、造数据、蹭没跑通的热点——素材是空的时候，它只会空转，会先追问你要真东西。

## 语言风格库（根据选题匹配风格）

不同选题适合不同风格。以下是目前已收录的风格，写脚本前先判断选题适合哪种，没有合适的就问你。

### 风格A：自嘲吐槽型

来源视频：29秒竖屏自拍示范（自嘲吐槽风格参考）
适用选题：个人经历翻车/踩坑/反差体验，带娱乐性、有流量属性的内容

> 企业老板千万不要搞AI

> 我为了把我的知识库打好
> 然后形成这个内容的流水化生产
> 我待在这个屋子里面就出不去了
> 没有出门
> 整整一个月的时间除了睡觉的时间
> 你看我都憔悴成什么样子的
> 憔悴是这样的看到没有
> 所以企业老板来千万别搞这个鬼东西
> 搞了这个鬼东西
> 你就出不了这个门
> 你就不能出去浪来呀

### 风格A特征（逐条对照，写完自查）

| 维度 | 规则 | 反例（禁止） |
|------|------|-------------|
| **口语纯度** | 100%口语，零书面语。用"鬼东西""出去浪"这种生活词 | "在当今数字化转型的背景下" |
| **句长** | 短句为主，单句不超15字。长想法拆成几句说 | 一句话超过20字 |
| **连接词** | 用"你看""然后""所以""看到没有"自然串联 | 用"首先""其次""综上所述" |
| **情绪驱动** | 带着吐槽/兴奋/无奈的情绪说，不是冷静分析 | 平铺直叙像念报告 |
| **自嘲幽默** | 敢笑自己（憔悴、出不了门），自嘲是建立真实感的工具 | 端着架子装专家 |
| **反向开场** | 用"千万别""不要搞"制造反差钩子 | "今天给大家分享一个方法" |
| **真实细节** | 具体数字+具体状态（整整一个月、除了睡觉、没出门） | "很长一段时间""经常" |
| **画面互动** | 写出跟镜头互动的提示（指自己、展示、看到没有） | 纯文本没有画面感 |
| **首尾呼应** | 开头的话结尾再说一遍，但用情绪递进不是总结 | "总结一下今天讲的…" |
| **不讲道理讲体验** | 不说"核心观点是"，全靠经历本身传递信息 | 直接抛概念/方法论 |

### 短视频模式（30秒-1分钟 · 5段结构）

短视频不需要走8步骨架，按这个结构来：

1. **开头钩子**（0-5秒）→ 一句话引起好奇（提问/反常识/反差）
2. **论据/论证**（5-18秒）→ 用事实、案例、对比支撑观点
3. **解决方案**（18-30秒）→ 给出明确的做法/答案
4. **观众能得到什么**（30-45秒）→ 点出看完这条视频他能拿走什么（实例/结果）
5. **结尾钩子**（45秒-结束）→ **默认金句收尾即止，不加评论区/私人联系方式类引导**；收口必须是「AI一起成长营 · 初级区模块 7天AI懂你」＋免费入口（《AI知识库搭建实操手册》《AI 同行实操案例》），并落在对准的卡点上；不许写成"评论区扣字/加好友领资料"

> 注：这是真实爆款视频提炼的通用结构，比早先的"反向钩子→真实经历→画面证据→收口"更贴近实际拍法，以后以5段结构为准。

### 长视频模式（3分钟+）沿用8步骨架，但语言调性不变

8步骨架管的是**内容结构**，语言风格管的是**怎么说**。选了风格A，长视频也要口语、短句、自嘲、情绪驱动——只是结构更完整。选了其他风格，则按该风格的语言规则写。

### 风格选择规则

- 写脚本前，先判断选题适合哪种风格
- 选题偏娱乐/反差/个人经历 → 风格A
- 选题偏专业/干货/教学 → 需要严肃讲道理的风格（待收录）
- 不确定时，问你"这条用哪种风格"
- 有新风格参考视频时，追加收录为新风格（风格B、C…）

## 快速启动

你投喂素材时，按以下格式收集输入：

```
选题/观点：[核心主张]
故事/案例：[具体事件或数据]

```

输出：可直接念的逐字稿 + 洞见标注。

如果你只给了选题没有故事/案例，先追问是否有具体事件或数据可补充。没有素材支撑的口播是空转的。

## 核心工作流：黄金骨架（8步）

按以下结构生成逐字稿，每段标注时长和功能：

1. **开场** → 一句话主张 / 问题 / 反常识（15-20秒）
2. **PROBLEM** → 现状困境 + 为什么 + 代价（30-45秒）
3. **故事/案例** → 发生了什么 → 转折点 → 结果（60-90秒）
4. **观点萃取** → 核心洞见一句话（20-30秒）
5. **对标迁移** → 2-3个不同场景的类比（30-45秒）
6. **落地行动** → 现在可以做什么 → 成功标志（15-20秒）
7. **收口** → 收口到「AI一起成长营 · 初级区模块 7天AI懂你」＋免费入口，并回扣本条对准的卡点；评论区只做纯互动提问，禁承诺回复；不放"扣字/加好友领资料"类话术
8. **结尾** → 回应开场 / 反问（5-10秒）

每段写完后标注预估字数，确保总时长匹配目标。

## 8大叙事库

根据你素材的切入点，选取最匹配的叙事框架来组织内容：

| 库名 | 触发信号 | 核心逻辑 |
|-----|--------|--------|
| 问题反转 | "大家都这么做，但其实…" | 先认同普遍做法，再揭示被忽略的另一面 |
| 单一解药 | "有个方法改变了我…" | 聚焦一个方法，展开它是怎么起作用的 |
| 成本降维 | "怎样快速/便宜/简单地…" | 降低认知门槛，让听众觉得"我也可以" |
| 阶段跨越 | "初级→中级→高级" | 用成长阶梯让听众看见自己的位置和下一级 |
| 权力转移 | "从被动到主动" | 强调从被环境支配到掌握主动权的转变 |
| 身份撬动 | "当我意识到我是…" | 用一个身份觉醒时刻驱动行为改变 |
| 因果颠倒 | "你以为的原因其实是结果" | 翻转常识的因果链，制造认知冲突 |
| 缝隙机会 | "没人做，但可以…" | 发现被忽略的机会点，用"为什么没人做"制造悬念 |

叙事库选定后，黄金骨架的每一段都围绕这个叙事逻辑展开，保持一致性。

## 质量防线

### 必须有

- 具体的故事或数据，不是纯概念堆砌
- 核心观点能一句话说清楚
- 至少一个可验证的逻辑链
- 用"通常""大多数"代替"永远""所有人"
- **收口到「AI一起成长营 · 初级区模块 7天AI懂你」＋免费入口，并回扣对准的卡点**（铁律，不可省略；知识库与内容生产系统是内容与证据，不是收口对象）

### 禁止使用

- 没有来源的论断
- 鸡汤式励志空泛语
- 因果链跳跃（A→C，缺B）
- 无边界的绝对结论
- 编造案例/数据/数字

### 输出自查

逐字稿写完后，逐段检查：

**逻辑层：**
- 有没有哪一段是"正确的废话"？（有就删或加具体）
- 如果开1.5倍速听，核心观点能不能被抓住？（不能就强化）
- **钩子收口是否自然？** 用户听完会不会觉得"我想拿那个手册"？（生硬就改过渡）

**语言层（对照所选风格）：**
- 这句话念出来像你本人在说话，还是像AI在念稿？（像AI就改）
- 有没有书面语混进来了？（有就拆成口语）
- 单句有没有超过15个字？（有就断句）
- 情绪在不在？（平的就加吐槽/自嘲/反问）
- 有没有"首先其次综上"？（有就删，换"你看""然后""所以"）

## 快捷指令

以下指令可在逐字稿生成后单独使用，对已有脚本进行迭代：

- **"诊断"** → 找出逻辑缺失的具体位置，标注修复建议。输出格式：逐段标注缺失项 + 修复方向。
- **"打磨"** → 调整口吻，让逐字稿更可念。重点改：书面语转口语、长句拆短句、增加自然停顿。
- **"对标"** → 找3个不同领域的同类解法，输出给你做类比素材。
- **"上强度"** → 质疑论述，找缺口和反例。输出：每个论点可能的质疑 + 建议的加固方式。
- **"最小化"** → 压缩到1分钟版本。保留核心观点 + 一个故事/案例 + 一句话行动。

## 深度视频微调（5min+）

当目标时长超过5分钟时，PROBLEM段不能照搬短版的45秒结构。改成**「铺垫递进」**：

- 把大问题拆成两个小问题
- 先问第一个，停顿，再问第二个
- 让听众体验"认知逐层打开"的感受

同时拉长故事/案例段（120-180秒），增加细节和情绪层次，让长视频有沉浸感而非拖沓感。
